🚨 DÉPANNAGE
═══════════════════════════════════════════════════════════════════

PROBLÈME: Les horaires ne s'affichent pas
SOLUTION:
• Attendez 30 secondes
• CTRL + SHIFT + R
• F12 → Console → vérifiez les erreurs
• Vérifiez que l'API Aladhan fonctionne

PROBLÈME: Les images de fond ne s'affichent pas
SOLUTION:
• Vérifiez que les 5 images .jpg sont uploadées
• CTRL + SHIFT + R
• F12 → Network → vérifiez le chargement des images

PROBLÈME: Les adhans ne jouent pas
SOLUTION:
• Vérifiez que adhan1.mp3 et adhan2.mp3 sont uploadés
• Testez dans Paramètres → Tester l'Adhan
• Vérifiez le volume (pas à 0)
• Certains navigateurs bloquent l'autoplay audio

PROBLÈME: Les notifications ne marchent pas
SOLUTION:
• Autorisez les notifications dans le navigateur
• Activez dans Paramètres
• Rechargez la page
• Testez avec une prière proche

PROBLÈME: La vidéo Ramadan ne joue pas
SOLUTION:
• Vérifiez que ramadan.mp4 est uploadé
• Le GIF s'affichera en fallback si la vidéo ne charge pas
• C'est normal sur certains vieux navigateurs
